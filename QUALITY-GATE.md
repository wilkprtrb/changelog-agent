## Why this gate exists

The #1 risk in the Changelog Agent is local-model writing quality. If qwen2.5:7b
produced stilted, generic, or hallucinated release notes, we would NOT force it —
we'd keep the human review gate and use the model only for grouping. This test
was run BEFORE building the full CLI, per the scope (§6.1).

## What was tested

Fed 9 real commits (grouped into 3 logical changes) to the model with the WRITE
prompt from the scope (§2 Stage 3). The model produced a plain-language,
customer-facing release note per change.
